# Scitalk Demo module

Installing the module will create some basic talk and collection nodes

For more detailed test content enable Single Content Sync module and
import the zip files in the imports file. Make sure to go into the Single
Content Sync configuration first and disable the Site UUID check.

# How to use Single Content Sync module

1. Enable Single Content Sync
2. Go to Administration > Configuration > Content authoring
   > Single Content Sync Settings and disable the Site UUID check
3. Go to Administration > Content > Import content
4. Upload the zip files in the imports folder

The all.zip archive will import a variety of talks and collections from
SciVideos, including some with links to the talk and some with YouTube videos.

The Secrets of the Universe talk is a complete single talk including
transcript and slides.
